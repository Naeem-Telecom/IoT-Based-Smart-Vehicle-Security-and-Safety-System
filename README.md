# IoT-Based-Smart-Vehicle-Security-and-Safety-System
IoT-based Smart Vehicle Security and Safety System using Arduino, GPS, GSM, MQ-3 Alcohol Sensor and Eye Blink Sensor.

## Overview

This project presents an IoT-enabled vehicle safety system designed to improve road safety by integrating multiple sensors with embedded hardware and communication technologies.

## Features

- Seat Belt Detection
- Alcohol Detection
- Driver Drowsiness Detection
- Accident Detection
- GPS Tracking
- GSM Emergency Alert
- Arduino-Based Control System

## Technologies Used

- Arduino Uno
- GPS Module
- GSM Module
- MQ-3 Alcohol Sensor
- Eye Blink Sensor
- Seat Belt Sensor
- Arduino IDE
- C/C++

## Objectives

- Prevent vehicle ignition if seat belt is not fastened.
- Prevent vehicle ignition if alcohol is detected.
- Detect driver fatigue.
- Send accident location via GSM and GPS.
- Improve overall vehicle safety.
